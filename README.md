# odin-recipes
The Odin Project, Project: Recipes

Recipes adapted from AllRecipes.

https://www.allrecipes.com/one-pot-teriyaki-chicken-casserole-recipe-11960287

https://www.allrecipes.com/recipe/240400/skillet-chicken-bulgogi/

https://www.allrecipes.com/recipe/238691/simple-macaroni-and-cheese/

Project aims: use basic html to create website with links, ordered and unordered lists, images, heading elements, and text. Used div id and div class, used css on a stylesheet and on the index.

I chose these recipes because they were all on the front page that day, and I actually ended up testing some of them.
I changed the recipes and used floating asides and floating divs to separate information that didn't need to be inside the recipes.

I like the look of drop caps and used them in the titles.

Used css on line items on index page because I didn't want to change all the unordered lists on every page. Hid the bullet points behind the page color because display="non" kept breaking the first image.
