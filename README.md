Project aims: use basic html to create website with links, ordered and unordered lists, images, heading elements, and text. 

I chose these recipes because they were all on the front page that day, and I actually ended up testing some of them.

I tested the skillet chicken bulgogi recipe and altered it. Bulgogi means "fire beef" in Korean and would be more authentic if it were at least cooked over a grill. There is nothing "Korean" about this recipe. I plan on using asides to talk about how to improve the recipe, to include add-ons, or cooking tips so that I can clean up the steps or ingredients lists. 

I also want to add drop caps because I think they look cool.
